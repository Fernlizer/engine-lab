# Honda CBR150 Phase 1 Open Questions

All questions are unresolved until evidence is registered and reviewed.

## Family boundaries

- What are the evidence-supported major engine generations?
- Which changes define a new engine generation rather than a trim, market, emissions, or model-year variation?
- What model and engine codes can be reliably mapped to each generation?
- Are code mappings globally consistent or market-specific?

## Markets and chronology

- In which markets and model years was each variant sold?
- Which factory documents are specific to each market, year, language, and revision?
- Which apparent specification conflicts are explained by market or homologation differences?

## Engineering parameters

- What are the bore and stroke for each verified variant?
- What is the compression ratio for each verified variant?
- What induction system is used?
- What cylinder-head architecture and valve count are documented?
- What gearbox configuration is documented?
- What claimed power and torque are stated, under which measurement standard and test conditions?
- What internal engine changes are documented between generations?

## Evidence quality and simulator selection

- Which generation has the most complete set of simulator-relevant inputs?
- Which generation has the strongest factory evidence?
- Which generation has reproducible direct measurements or trustworthy validation data?
- What contradictions remain for each candidate?
- Which engine should become the simulator v1 reference, and what evidence supports that choice?

## Method questions

- What canonical units and unit-conversion library should later be adopted?
- How will repeated measurements, uncertainty, and instrument calibration be represented?
- What licensing constraints apply to locally retaining manuals, catalogs, dyno plots, and web captures?
